To illustrate the wealth of information and form prior distributions for the confined diffusion model, we can simulate the diffusion process of a control molecule diffusing in a confined electrostatic environemnt. 

The goal of this project was to model the diffusion process of confined diffusion using literature, and utilize pre-existing theory to for a statistical estimator of surface charge from diffusion dyanmics.

\section{Simulation Equations}

The simulation scheme follows that descirbed in \cite{millanNumericalSimulationsConfined2023}. A brownian particle diffuses between two walls such that $(x,y)$ are perpendicular to the walls, and $z$ is parallel. The electrostatic force that the particle feels is then only in the $z$ direction. The diffusivity of the particle will depend on the distance of the walls. The langevin equation simulated, 
\begin{equation}
    m\ddot{\vec{x}(t)} = - \lambda \dot{\vec{x}(t)} + \vec F(\vec{x}(t)) + \sqrt{2k_b T \lambda} \vec{W}(t),
\end{equation}
is first seperated into transverse and axial components, where $F$ is the electrostatic force, $\lambda$ is the friction. Here, we can re-write the diffusion coefficient using the Stokes-Einstein relation,
\begin{equation}
    D(z) = \frac{k_b T}{\lambda(z)}.
\end{equation}

Then, in overdamped regime, where $m \ddot{\vec{x}} \ll 0$, we can write the equations of motion as
\begin{equation}
    \begin{aligned}
        \frac{dx}{dt} &= \sqrt{2D_x(z)} W_x(t) \\
        \frac{dz}{dt} &= \sqrt{2D_z(z)} W_z(t) + \frac{F_z(z)}{\lambda(z)},
    \end{aligned}
\end{equation}
as descirbed in Eqn. 7 of \cite{millanNumericalSimulationsConfined2023}. This is exceptionally valid for particles between $\SI{10}{\nm} - \SI{100}{\micro \meter}$ as this is exactly the overdamped regime for many particle materials, such as PMMA or coated polystyrene.

To simulate this equation, we use an Euler-Maruyama scheme. To illustrate this, we can rewrite the above equations in the Ito form, replacing lowercase variables with their captial, stochastic, equivalents:
\begin{equation}
    \begin{aligned}
        dX_t &= \sqrt{2D_x(z)} dW_x \\
        dZ_t &= \sqrt{2D_z(z)} dW_z + \frac{F_z(z)}{\lambda(z)} dt,
    \end{aligned}
\end{equation}

The simulated system of equations is then the pair of equations;
\begin{equation}
    \begin{aligned}
        x_{n+1} &= x_n + \sqrt{2D_x(z_n)} W_{x,n}\Delta t\\
        z_{n+1} &= z_n + \left[D'_z(z_n) - \beta D_z(z_n) V'(z_n) + \sqrt{2D_z(z_n)} W_{x,n}\right]\Delta t\\
    \end{aligned}
\end{equation}
where $V(z)$ is the electrostatic potential, $\beta = 1/k_b T$, and $\Delta t$ is the discretized time. 

\section{Surface Charge Estimator}

As described earlier, the relations for the effective potential are described if one knows the particle properties and surface charge. In terms of measureables, electrostatic interactions can be fully described by the following  equation,

\begin{equation}
    U(z) = B\left[e^{-(H - z)/\lambda_D} - e^{-(H + z)/\lambda_D}\right],
\end{equation}
where the prefactor is described by the map $f: (\zeta_p, \sigma_w, a, \lambda_D, T)$,
\begin{align}
    B &= C \cdot \tanh\left(\frac{e_0 \zeta_p}{4k_b T}\right) \cdot \tanh\left(\frac{e_0 \psi_w}{4k_b T}\right) \\
    C & = \frac{64 \pi \varepsilon_0 \varepsilon_r a k_b T}{e_0^2}\\
    \psi_w &= \frac{2k_b T}{e_0}\text{asinh}\left[\frac{\sigma_w e_0 \lambda_D}{2 \varepsilon_0 \varepsilon_r k_b T}\right]
\end{align}
where $\zeta_p$ is the zeta-potential of the particle, $\psi_w$ is the stern-layer potenital for the surface walls, $a$ is the particle radius, $e_0$ is the elementary charge value, and $\lambda_D$ is the debye-length.

\subsection{Radial Integral}

Image data will have background misalignment due to iSCAT hardware setup. To optimize for fitting speed and misalignement property, radial scattering profile are assumed as in the rayleigh regime model is symmetric. The radial integration method is described in Alg \ref{alg:rad_int}.

\begin{algorithm}[H]
    \caption{Discrete Radial Integral}
    \label{alg:rad_int}
    \begin{algorithmic}[1]
        \Require $\text{I}\{F, H, W\}$, list of image ROIs\\
        $\theta_0$, starting angle
        $\Delta \theta$, Angular integration distance
        $R$, polar integration bound
        \State $\text{rad\_av\_arr}$ = []
        \State $m = \text{Disk}[R, \theta_0, \theta_0 + \Delta \theta]$
        \For {$t=1$ to $F$}
            \State $v = I[m]$
            \State $\text{rad\_av\_arr}[t] = \sum_\theta v$ 
        \EndFor
        \State \Return $\text{rad\_av\_arr}$
    \end{algorithmic}
\end{algorithm}

\subsection{Nuisance parameter Estimation}

To obtain accurate estimation of the $z$ position relative to nearby frames, nuisance estimation is done to focus on $z$ fitting. To do this, L-BFGS-B Fitting is performed. alongside amplitude fitting. This is described in the algorithm below. 

\subsection{2D Chainlink}

To link consequent positions in space, a dynamic programming algorithm is used. The algorithm is descirbed in Alg. \ref{alg:best_chain_2d}

\begin{algorithm}[H]
\caption{Dynamic Programming for Best 2D Chain of Points}
\label{alg:best_chain_2d}
\begin{algorithmic}[1]
\Require 
    $\text{min\_idx} = \{ \text{min\_idx}[t] \}_{t=0}^{F-1}$, list of candidate positions per frame\\
    $\text{min\_vals} = \{ \text{min\_vals}[t] \}_{t=0}^{F-1}$, list of candidate values per frame\\
    $w = (w_x, w_y)$, weighting for distance computation (default $(1,1)$)\\
    $\text{max\_step}$, optional maximum allowed step distance
\Ensure
    $\text{idx\_chain}, \text{x\_chain}, \text{y\_chain}$, the indices, positions, and values of the optimal path

\State Initialize $F \gets |\text{min\_idx}|$
\State Initialize $cost[i] \gets 0$ for all $i$ in frame $0$
\State Initialize $prev \gets []$ \Comment{to store predecessor indices}

\For{$t = 1$ to $F-1$}
    \State $A_x \gets \text{min\_idx}[t-1]$, $B_x \gets \text{min\_idx}[t]$
    \State $A_y \gets \text{min\_vals}[t-1]$, $B_y \gets \text{min\_vals}[t]$
    \State Compute pairwise differences:
        \[
        \Delta_x[i,j] = |A_x[i] - B_x[j]|, \quad 
        \Delta_y[i,j] = |A_y[i] - B_y[j]|
        \]
    \State Compute weighted Euclidean distances:
        \[
        D[i,j] = \sqrt{ (w_x \Delta_x[i,j])^2 + (w_y \Delta_y[i,j])^2 }
        \]
    \If{max\_step is not None}
        \State Set $D[i,j] \gets \infty$ if $D[i,j] > \text{max\_step}$
        \If{no finite $D[i,j]$ exists}
            \State \Return empty path
        \EndIf
    \EndIf

    \State Compute cumulative path cost matrix:
        \[
        M[i,j] = cost[i] + D[i,j]
        \]
    \State For each node $j$ in frame $t$, find predecessor $p[j]$ minimizing $M[:,j]$:
        \[
        p[j] = \arg\min_i M[i,j], \quad
        new\_cost[j] = M[p[j], j]
        \]
    \State Update $cost \gets new\_cost$
    \State Append $p$ to $prev$
\EndFor

\State Initialize $j \gets \arg\min_i cost[i]$  \Comment{index of minimal total cost in last frame}
\State Initialize $\text{idx\_chain} \gets [0]^{F}$, set $\text{idx\_chain}[F-1] \gets j$
\For{$t = F-2$ down to $0$}
    \State $\text{idx\_chain}[t] \gets prev[t][\text{idx\_chain}[t+1]]$
\EndFor

\State Compute chains:
\[
\text{x\_chain}[t] = \text{min\_idx}[t][\text{idx\_chain}[t]], \quad
\text{y\_chain}[t] = \text{min\_vals}[t][\text{idx\_chain}[t]]
\]

\State \Return $\text{idx\_chain}, \text{x\_chain}, \text{y\_chain}$
\end{algorithmic}
\end{algorithm}

\subsection{3-parameter Estimation}

As a reminder, the model for the iPSF is a multivariate function $\text{iPSF}:(z, E_0, \gamma) \rightarrow \R^2$. It has been shown that the statistical model of $\text{iPSF}$ takes;
\begin{equation}
    \begin{aligned}
        \hat{E_0} &\sim \text{Gamma}(\mu_{E_0}, \sigma_{E_0}) \\
        \hat{\gamma} &\sim \text{logNorm}(\mu_{\gamma}, \sigma_{\gamma}) \\
    \end{aligned}
\end{equation}

The so-called 3-parameter estimation is a sampling of nuisance parameters in the model. The nuisance parameters here are $\hat{E_0}, \hat \gamma$, where $\hat{E_0}$ is an ampltiude factor, and $\gamma$ is an exponential decay factor used to account for spatial decay in signal. The amplitude factor can be analytically solved for using a grid-search sweep along $z$. The $\gamma$ factor is fitted to using the L-BFGS-B minimization algorithm. This nuisance parameter fit is shown in the histograms of these two parameters shown in Fig. \ref{fig:nuisance_fit}.

\subsection{Grid-Search Estimation}

Once the nuisance parameters are chosen, a gridsearch with a dynamic linking is performed. Each frame is assumed to have a maximal diffusion time. This is in place to optimize for noise and have coherent, physical traces without outliers. The grid search takes the difference between the data and a scan over the model with the nuisance parameters in place. The best loss is chosen. In the case of linking, the minimal loss over the path is chosen. The full algorithm is discussed elsewhere. the residuals of this using no fitting are shown in Fig. \ref{fig:fit_residuals}.
